# Handoffs

Write a dated task note using [_template.md](_template.md) before an agent stops. Include actual evidence, next steps and unresolved decisions. A note that says see chat is incomplete. Remote merge and integration validation states require their actual evidence.

Dated handoffs preserve what each actor observed at that stage. Earlier “no app,” “in review,” or “no remote” statements describe their historical task, not current repository state. Use [STATUS](../../STATUS.md), [ROADMAP](../../ROADMAP.md) and the [ADR index](../adr/README.md) for current implementation and merge status. Temporary scripts or screenshots named in a handoff were not committed unless explicitly linked to a repository file; their historical counts are recorded observations, not publicly reproducible artifacts.
