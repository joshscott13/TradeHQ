# Planner session record template

Blank template for [the usability kit](usability-test-kit.md). No participant, consent, result or finding is prefilled. Store completed raw records privately outside the public Git repository. Publish only an appropriately consented anonymized synthesis.

## Session and consent

- Anonymous session ID (optional), date and moderator:
- Build commit, URL, browser, viewport/device, input method and relevant zoom/access needs:
- Participant's stated firms/exact programs/platforms and trading/tracking experience (omit identifiers):
- Consent to anonymous notes: yes / no / not requested; how and when obtained:
- Optional recording/record-viewing consent, purpose, access and deletion date (otherwise none):
- Private evidence location/access owner (do not place sensitive links in public notes):
- Tasks skipped, reason and any protocol/build deviations:

If notes are declined, do not create a participant record. A pseudonym is not consent to publish. Record factual consent status; do not infer it from attendance.

Keep input-setting mistakes, engine mismatches and interpretation mistakes distinct. A source or arithmetic mismatch is a build/protocol finding; an expected output alone is not a usability result. Assistance prevents independent-success scoring even if the final answer is correct.
