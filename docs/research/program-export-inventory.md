The inventory records the phase-specific payout source; do not erase funded consistency using a general evaluation comparison. Confirm applicability before implementing eligibility.

## Private sample collection checklist

Use maintainer-controlled private storage outside the repository; agree access and deletion scope before collecting anything. Do not attach private originals to public issues/PRs, commit them, or provide credentials. A local ignored folder alone is not the agreed retention policy.

1. Provide a metadata note per anonymous account: firm, exact program, nominal size, phase, purchase/reset dates and options, connection/application/version, instrument and currency, report name, date range, timezone/session boundary, export date and filters.
2. Keep the original privately. Make a redacted copy preserving headers, row order, delimiters, decimal/date formatting, quantities, prices, fees, timestamps and row relationships. Replace identifying fields consistently with `FAKE` aliases; retain distinct account/order/execution identities and provide a private redaction note. Remove personal names, email, payment/bank details, tokens and unrelated accounts. Do not fabricate missing rows or costs. If necessary trade values cannot be shared, record that constraint and keep reconciliation pending.
3. Include one normal trading week if available, plus examples of partial fills/exits, a losing/flat result and commissions. Supply a second overlapping export for duplicate discovery. Request overnight/DST/correction/copy cases only when genuinely present; absent cases stay gaps, not invented real evidence.
4. Include an independent statement or dashboard snapshot for the same account, filters and period, with gross/net/cost definitions and generation time. The total must not merely be recomputed from the proposed parser. Separately provide redacted firm invoices and payout request/approval/receipt evidence where cash reconciliation is in scope.
5. Record consent, allowed use, private storage owner, access scope and deletion date. Only approved synthetic `FAKE` fixtures and nonidentifying reconciliation notes may enter Git after review; a real redacted file is not automatically public-safe.
