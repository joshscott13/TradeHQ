# Review records

Dated reports preserve each reviewer's scope, actors, observed commands, counts, findings and disposition at the time of review. They are not automatically updated when later features merge. Use [STATUS](../../STATUS.md), [ROADMAP](../../ROADMAP.md) and the [ADR index](../adr/README.md) for current scope. Earlier bootstrap-only limitations remain historical evidence.

An external temporary oracle or screenshot named without a repository link is an uncommitted review aid. Historical counts and screenshot assessments remain attributed to their original actors; those artifacts are not publicly reproducible from this checkout. Committed tests and tooling provide the reproducible checks. No report establishes actual user demand, real export reconciliation or full accessibility certification unless it names that evidence explicitly.
