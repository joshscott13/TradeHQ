# release procedure

Require authorization for the target version. Check origin/main and full verification, independent approvals and nonempty Unreleased. Reconcile changelog/version, create the authorized signed tag and release, then verify remote artifacts. Merged prototype features and Docker packaging do not authorize a versioned release or public deployment. Before a persistent or hosted release, complete the applicable real deployment, restoration, privacy and authentication gates in [PLAN](../PLAN.md); do not describe prototype container checks as those results.
